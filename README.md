# AyurCare — Clinic Desk

A small, responsive, browser-based clinic administration starter project built with plain HTML, CSS and JavaScript.

## Features

- Patient profile registration and search
- Appointment scheduling
- Therapy/session record keeping
- Dashboard summary and upcoming appointments
- JSON data export
- Browser `localStorage` persistence (data stays in the current browser)

## Run locally

No build tools or installation are required.

1. Download or clone this repository.
2. Open `index.html` in a modern browser.
3. Add fictional demo patients and explore the sections.

You can also use GitHub Pages to host the static demo: in the repository, open **Settings → Pages**, select the `main` branch and `/ (root)`, then save.

## Data and privacy warning

This is an educational starter project, **not** a production electronic health record (EHR) and not a certified medical device. It has no authentication, server-side access controls, encryption, audit trail, secure backup, or multi-user support. Data is stored unencrypted in the browser's local storage.

**Do not enter real patient-identifiable or sensitive health information.** Before any real-world clinical use, obtain appropriate security, privacy, legal and regulatory review; implement authentication, authorization, encryption in transit and at rest, audit logging, retention controls, secure backups and a tested recovery process.

The app is an administrative record-keeping demo only. It does not diagnose conditions, recommend procedures, or prescribe treatment. Clinical decisions must be made by qualified professionals following applicable standards and local regulations.
